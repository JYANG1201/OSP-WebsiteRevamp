## Typing URL into Address Bar

URL parameters are query strings used to pass information about a search through a URL. Most queries in a URL start with a question mark and are used in different manners.

The prefixes www. And HTTP:// are **optional**.

Some websites even use **shorter URLs** that divert users to the principal or full URL when clicked, thereby allowing users to have access to the website without having to input long strings of words.

For example, instead of typing _www.pinterest.com_, you can type in _pinterest.com_ into your address bar and will be taken to the website in no time.

### URL Parameters

URL parameters (query strings or URL query parameters) are keywords or [](https://onesearchpro.my/website-elements/)**[website elements](https://onesearchpro.my/website-elements/)** present in a URL to organize, filter, and pass information about the website.

They are a way to pass information about the URL clicked itself.

A URL parameter can be identified by looking at the portion of the URL that comes after the question mark (?). They consist of a value and key which can be separated by the equal to (=) sign.

Multiple values can be separated by the (&) ampersand.

### What is Google Custom Search?

The Google Custom Search helps you add custom search boxes on your site so users in need can use it to find what they’re looking for. Google Custom Search is public and free to use. The only downside to using the platform is the number of websites that will display on your website.

E-commerce platforms like Shopify and other [](https://onesearchpro.my/best-website-builder-for-seo/)**[website builders](https://onesearchpro.my/best-website-builder-for-seo/)** like Wix and WordPress, come with a default search bar.

You can also manually copy and paste the code so it can be functional on your website. Here’s how to add the Google Custom Search engine to your website:

1.  Open the Google Custom Search Homepage.
2.  Type the URL of your website and click on the create option just below it.
3.  Your custom search engine is created and you can give it a name that you prefer.
4.  If you wish to add another website, click on **‘Add’** at the top.
5.  After creating a custom search engine for your website, click on the control panel and you’ll see a basic tab. You can add it to your website by clicking on **‘Get a code’**, so you copy and paste the code in the website editor. Or you can copy the search engine ID and paste it under the Google Custom Search plugin.
6.  Refresh your website and the Google Custom Search engine would go live.

### How to exclude a website from Google search results?

A Google Custom search helps and can be used to perform this function. Enter the website, input _\-URL: \[ write URL here\]_. The search operator (-inurl) must appear before the search query to make it work properly.

Let’s say you want to remove content from a random website “googleme” in a search query. You would just input: google me -inurl:googleme.com.
